Settings

General Defaults

Default format used for batch downloads

Available variables:
{date} - Current date (YYYY-MM-DD)
{title} - Video title (sanitized)
{videoId} - YouTube video ID
{channel} - Channel name
{lang} - Language code (e.g., en, es)
{ext} - File extension
Example: {date}_{title}.{ext} → 2025-12-07_My_Video.txt
